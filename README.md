# Ju Vellasco Confeitaria

Site estático feito em HTML, CSS e JavaScript, com layout responsivo, navegação móvel, brilho de vidro nos botões, zoom sutil nas fotos e animações de entrada durante a rolagem.

## Como abrir

Abra index.html em um navegador. Para publicar, envie a pasta inteira ju-vellasco-site, incluindo a pasta assets.

O formulário e os botões de redes sociais estão apenas visuais, conforme solicitado. As fotos e o selo da marca são recortes da imagem de referência anexada; a logo tem fundo transparente.
